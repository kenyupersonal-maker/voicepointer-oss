# VoicePointer HUD assets

These transparent 2x PNGs are deterministic Chromium renders of the vector
layers exported from Figma file `Yu0UtaxB3pfj4Q4HZNz66S`, nodes `7:638`,
`7:660`, and `7:705` on 2026-09-03.

They preserve Figma's blur and shadow filters that macOS CoreSVG drops. The
full-node PNG exports are intentionally not bundled because Figma flattened
them onto an opaque white canvas.
